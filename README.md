# inline 訂位快手

一個可放進 Git 的 Chrome／Edge Manifest V3 瀏覽器擴充功能。此版本針對辛殿麻辣鍋信義店，預設 3 位、12:00，日期可從未來 30 天隨機選擇。

## 功能

- 儲存餐廳官方 inline 訂位網址
- 設定用餐日期、時間、人數與開放時間
- 到點自動開啟一次，不輪詢、不高頻刷新
- 可在開放前 0–30 分鐘先開一次官方頁暖機，確認登入並讓瀏覽器準備好
- 透過 inline 頁面支援的 `pre_filled_form` 參數預填資料
- 可先按「現在開啟測試」確認連結與預填內容
- 所有設定只存在瀏覽器本機，不含帳號、密碼或信用卡資料
- 僅要求瀏覽器的排程與本機儲存權限，不要求讀取網頁內容
- 自動選擇 3 位與 12:00、填入聯絡資料並推進流程
- 遇到 CAPTCHA 暫停；你手動完成後，插件會偵測頁面變化並繼續
- 無付款、訂金或 OTP 時，可選擇自動送出最終訂位
- 彈出視窗顯示「自動更新」狀態與目前版本；Git 開發版會明確提示需手動重新載入

## 安裝

1. Chrome 開啟 `chrome://extensions`；Edge 開啟 `edge://extensions`。
2. 開啟右上角「開發人員模式」。
3. 按「載入未封裝項目」。
4. 選擇本資料夾 `inline-reservation-helper`。
5. 把插件釘選到瀏覽器工具列。

## 使用

1. 到餐廳的 inline 官方訂位頁，複製網址；網址應以 `https://inline.app/booking/` 開頭。
2. 打開插件，填入餐廳、用餐日期、用餐時間、人數與該餐廳公布的訂位開放時間。
3. 在插件內填入姓名、手機與 Email；資料只儲存在瀏覽器本機，不會進入 Git。
4. 日期留白時，每次從未來 1–30 天隨機挑一天。若要指定日期再填入。
5. 按「現在啟動自動訂位」，或填寫啟動時間後按「儲存並啟用」。
6. 出現 CAPTCHA 時由你手動完成；通過後插件會自動接續。
4. 「提前暖機」建議保留 5 分鐘；暖機頁出現後先確認帳號狀態，並讓電腦保持清醒。
5. 回到插件按「儲存並啟用」。開放時間到時，瀏覽器需保持開啟。
6. 準點頁開啟後，立刻選擇剩餘時段、檢查餐廳規則與訂金，再自行送出。

## Git / GitHub

此資料夾可以直接成為 Git repository：

```powershell
git init
git add .
git commit -m "Initial inline reservation helper"
```

之後可建立私人 GitHub repository 再推送。程式不會把你的訂位資料寫進原始碼，因此可公開；若你日後自行加入姓名、電話、token 或付款資訊，請勿提交，並把相關檔案加入 `.gitignore`。

## 使用界線

這是個人訂位輔助工具，不是搶位機器人：

- 使用者勾選「無付款／OTP 時自動送出」後，才會自動按下最終訂位
- 不會繞過 CAPTCHA、簡訊驗證或存取限制
- 會自動點擊正午 `12:00`；若因此出現人類驗證，就暫停等待你手動完成
- 只接受 `12:00`、`12：00`、`中午 12:00` 等正午寫法，不會改選 11:30、12:30 或凌晨 00:00
- 若第一次點時段或「完成預訂」觸發 CAPTCHA，手動通過後會依頁面實際狀態重試一次；仍失敗就停下提示手動操作
- 不會爬取座位、呼叫未公開 API 或持續刷新
- 不應用於代訂、轉售、轉讓、囤位或造成服務負載
- 餐廳與 inline 當日顯示的規則永遠優先

使用前請自行閱讀 [inline 使用條款](https://restaurant.inline.app/tos) 與餐廳訂位規則。

## 已知限制

- 預填不等於保證有位；最後仍取決於餐廳當下庫存。
- 某些餐廳的流程、訂金或必填欄位不同，仍需手動完成。
- 電腦休眠時不會被插件喚醒；電腦恢復後，瀏覽器才會處理錯過的排程。
- inline 若更改預填參數，需更新插件。
